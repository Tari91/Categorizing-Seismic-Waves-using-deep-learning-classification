 **Seismic Wave Classifier**

This project is a deep learning-based classifier for identifying different types of seismic waves — P-Waves, S-Waves, and Surface Waves — using synthetic time-series data.



🚀 **Features**

Synthetic data generation for seismic waveforms  
Deep learning classifier using 1D CNN  
Accuracy tracking and visualization  
Fully contained in a single script  
Exported version available in `.py` and `.xlsx`  


📦 Requirements

Install dependencies using:

pip install numpy matplotlib scikit-learn tensorflow


🧪 How to Run

python seismic_wave_classifier.py


📊 Output

Prints training and test accuracy

Displays a graph showing training vs validation accuracy over epochs


📁 Files Included

seismic_wave_classifier.py — Main script

seismic_wave_classifier.xlsx — Excel format of the script (for reference or documentation)

README.md — Project overview and instructions
